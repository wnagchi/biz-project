# v0.5.1

发布日期：2026-10-20

修复 `v0.5.0` 首次 GitHub CI 发现的 Windows 路径兼容问题，并校正异步快照测试的观察时机。保留已发布的 `v0.5.0` 标签和记录。

## 修复内容

- Windows 下，Git 可能把同一目录的 8.3 短路径展开为长路径。现在通过原生路径解析比较现有别名，确保“不参与记录”选择在项目初始化 Git 后仍被识别。
- 原有偏好文件、身份和路径不会因别名比较被重写；没有新增数据格式或自动迁移。
- Worktree 测试使用实际目录比较别名；目录删除快照测试等待所有目标文档完成，不跳过检查或放宽超时。
- 发布步骤先推送主分支并等待该提交的 CI 通过，再创建版本标签，避免把首次运行才发现的问题直接标记为新版本。

## 升级

更新到 `v0.5.1` 对应源码即可，无需迁移记录中心或重装 Skill。目录链接安装者随源码更新；已运行的后台服务要在保存草稿后由使用者明确重启，才能加载修复。

```sh
git fetch --tags origin
git switch --detach v0.5.1
```

若准备继续开发，应回到自己的开发分支。Node.js 20+ 的运行要求、LAN 策略和 MIT 协议均不变。版本发布不自动升级现有本机服务。

完整变化见 [更新记录](../../CHANGELOG.md)，后续发布遵循 [版本规范](../versioning.md)。
