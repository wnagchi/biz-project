# v0.5.0

发布日期：2026-10-20

Biz Project 的首个对外源码版本，从本版本开始维护统一的版本与变更记录。此前工程中的 `0.1.0` 是内部占位版本，不是一次公开发布。项目仍处于 `0.x` 迭代阶段。

## 包含的能力

- 项目、功能、独立进展的集中 Markdown / JSON 记录，以及本地 Codex / Cursor 接入。
- 本地管理平台：三栏工作台、搜索、状态/时间分组、Markdown 源码/预览、冲突检查与草稿保护。
- 文档快照和共享服务生命周期，独立的开发规则模块/方案管理，以及本机外部应用联动。
- MIT 协议、中文 README 与使用手册、贡献/安全说明、Issue / PR 模板及 GitHub CI。
- 隐私忽略规则与提交候选检查，防止本机入口、真实记录、配置、常见凭据和私人路径进入源码版本。
- 版本一致性校验：package.json 为版本源，同步锁文件、更新日志、版本说明与 `v0.5.0` 标签。

## 获取与使用

```sh
git clone --branch v0.5.0 https://github.com/wnagchi/biz-project.git
cd biz-project
npm run setup
npm start
```

运行需 Node.js 20+。仓库包含预编译界面，运行平台无需安装前端开发依赖。首次接入由使用者确认外部记录中心和项目，不自动迁移真实记录。

Windows 可使用 `install.cmd` 和 `start.cmd`。主动启动的平台默认接受私人 IPv4 局域网，同网段设备可查看和编辑记录；只需本机访问时使用 `npm start -- --no-lan`，已运行实例请核对本机设置。HTTP 不加密，仅用于可信私人网络。

## 验证与已知边界

维护者使用 `npm run version:check`、`npm test`、`npm run check`、`npm run build:web` 和 `npm run check:privacy -- --staged` 验证待发布内容；GitHub Actions 的实际结果以仓库 Actions 页面为准。

当前不提供云同步、团队账号、Agent 自动调度或自动部署。版本号与服务握手/数据格式的 schema_version 各自独立；本次没有数据格式迁移，也不替换使用者正在运行的服务。源码标签发布不等于 npm 包、安装包发布或现有本机服务已经升级。

隐私检查仅覆盖常见模式，不扫描完整 Git 历史或二进制内容。详情见 [隐私指南](../privacy.md)、[安全说明](../../SECURITY.md) 与 [使用手册](../usage.md)。
